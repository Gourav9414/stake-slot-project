# Playable local prototype

From the repository root, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/web/` in a browser.

This is a virtual-credit front-end demonstration. It generates demo outcomes in the browser and is not connected to Stake Engine/RGS or a wallet. Do not use it for real-money play or treat it as an approved Stake client.
